# Zotero Gemini Notebook v0.5.1

This release adds a ready-file badge to the Chrome toolbar icon and improves uploads in German-language Gemini Notebook.

- On Gemini Notebook tabs, the extension icon shows the number of files staged in Zotero: **1–9**, then **9+** for larger batches. It clears when no files are ready or Zotero is unavailable, and stays hidden on other websites. The count refreshes on tab changes, after an import claims the batch, and approximately every 30 seconds while a notebook tab is open.
- Improved detection of localized **Add sources** controls and handling of Gemini Notebook's hover-triggered upload interface. German-language testing passed before merge.
- Updated the build toolchain, Zotero plugin toolkit, and dependency security fixes.

The badge uses Chrome's `alarms` permission to refresh the local status count. These checks do not retrieve filenames or file contents; host permissions are unchanged.

## Updating

The Zotero plugin and Chrome companion are both version **0.5.1**. **Update the Zotero plugin before installing the 0.5.1 Chrome companion.** The 0.5.1 plugin continues to accept companions 0.4.0, 0.4.1, and 0.5.0 while users update. Older plugins with an explicit compatibility list will ask for a Zotero plugin update before accepting companion 0.5.1.

The Zotero plugin updates through Zotero's automatic updater once this release is promoted. Store-installed Chrome extensions update after Google approves and publishes the Chrome Web Store update. For an unpacked installation, replace the extension files, reload the extension, and refresh open Gemini Notebook tabs.

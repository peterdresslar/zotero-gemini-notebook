Configure MCP Prepare this Zotero profile for a local MCP client such as Codex or Claude. MCP support is off by default. Off MCP support is disabled. Enable MCP support This preference alone does not install an adapter or configure an MCP client. Client setup MCP client Runtime executable Browse… Select the uv executable that will eventually launch the external MCP adapter. Adapter entrypoint Browse… Select the FastMCP adapter's server.py entrypoint. Zotero will not execute it from this dialog. Client configuration location This location is recorded for setup guidance only. Zotero will not read or modify the client configuration file. Apply Defaults Uses the usual locations for the selected client on this computer. Adapter integration is not connected yet. Saving this dialog records preferences only. It does not create credentials, enable network endpoints, execute commands, or change MCP client files.
